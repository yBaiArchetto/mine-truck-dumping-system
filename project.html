建设范围与体系构成

服务端 Web 管理端

面向调度、计量、安全与系统管理人员的业务操作与数据管理界面，内网部署。

可视化看板

面向调度中心的实时作业、点位分布、告警与识别流水集中展示。

移动端 H5

面向现场作业人员的轻量操作：识别核对、补录、告警复核与上报。

体系覆盖：三大核心（车牌识别与自动计次、倒矿作业过程管控、车辆定位与告警复核）+ 八大功能模块 + 接口 / 性能 / 安全 / 验收 / 培训 / 售后 / 进度 / 风险。

协作与变更机制

  • 周例会 + 项目周报，同步进度、缺陷与协调事项。

  • 需求变更须双方书面确认，签订补充协议或变更单后执行。
  • 关键岗位设置 AB 角，降低人员变动风险。

验收组织与试运行

  • 功能验收：对照《需求规格说明书》逐项核验，功能实现率 100%。
  • 性能验收：车牌识别准确率、计次准确率、告警时延、并发能力、可用率、查询响应全部达标。
  • 试运行：连续试运行不少于 2 个月，运行稳定、无重大缺陷。
  • 文档验收：交付文档齐全、规范。
  • 验收组织：甲方组织验收会议，必要时邀请外部专家，形成《项目验收报告》双方签字盖章后通过。

验收不合格处理

  • · 乙方整改期不超过 30 日，无偿整改。
  • · 整改后仍不合格，甲方有权解除合同。
  • · 解除合同时乙方退还已收款项，并支付合同总价款 10% 违约金。

风险与应对要点

甲方硬件不满足接入条件

应对：乙方提前提出接入要求与参数建议，双方书面确认变更。

关键人员变动

应对：关键岗位 AB 角，项目负责人更换须甲方书面同意。

数据安全与保密

应对：内网部署、加密传输、操作审计、定期备份与全员保密承诺。

需求变更导致工期与成本波动

应对：变更书面确认，追加工作量签订补充协议。

接口联调延迟

应对：提前明确接口清单与联调计划，设立周度联调节点。

试运行期间缺陷处理

应对：问题台账登记，按级别限时修复并回归验证。
