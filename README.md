# 矿井货车倒矿智能管控系统 · 模拟版（可运行）

> 课程实验项目 · 第八组
> 本目录是**可运行的模拟系统**：在原型页面基础上加入了图片上传、文件名解析、自动计次、告警复核与全站数据联动。
> 全部功能纯前端实现，**不需要后端、不需要数据库、不需要联网**，双击页面即可运行。

---

## 一、这是什么

系统模拟了「车辆图片接入 → 识别 → 计次 → 告警 → 看板」的完整链路。为了在没有真实相机、地磅、GPS 的条件下可演示，做了三处模拟：

| 真实系统 | 本模拟版做法 |
| --- | --- |
| 相机抓拍车牌 | **上传图片**，识别结果由**文件名解析**得出（不做真实 OCR） |
| 矿斗满载检测 | 文件名中的矿斗标识（00 满载 / 01 低于阈值） |
| 地磅称重 | 页面手工**录入毛重、皮重**，系统自动算净重 |

> ⚠️ 识别结果来自文件名约定，不是图像识别。报告与演示中请如实说明这是**模拟实验**。

## 二、快速开始

1. 双击 `upload.html`（Chrome / Edge）；
2. 点页面上的**样例按钮**（会自动生成一张图片并上传），或自己选图上传；
3. 上传后看解析结果，再点左侧导航去「工作台 / 识别计次 / 告警复核 / 统计报表」看数据同步。

注意事项：

- 所有页面要用**同一种方式**打开（都双击本地文件，或都通过同一地址访问），否则浏览器当作不同来源，本地数据不互通；
- 页面更新后若没变化，按 **Ctrl + F5** 强刷；
- 数据存在浏览器本地，换浏览器或清缓存会丢，可用右上角「导出数据」留档。

## 四、图片命名规范（4 段）

```
车辆编号_点位_置信度4位_矿斗.jpg
例：01_01_0984_00.png
```

| 段 | 示例 | 含义 | 说明 |
| --- | --- | --- | --- |
| 1 | `01` | 车辆编号 | 2 位数字，车牌从车辆档案按编号取 |
| 2 | `01` | 点位编号 | `01` 卸矿平台 / `02` 排土点 / `03` 计量点 / `04` 北部卸矿平台 / `00` 未记录 |
| 3 | `0984` | 置信度 | 4 位数字，除以 1000 → 98.4% |
| 4 | `00` | 矿斗状态 | `00` 满载 / `01` 低于阈值 |

**时间不写在文件名里**：记录时间取上传那一刻（日期 + 时分秒由系统写入）。

### 兼容的旧写法

| 段数 | 示例 | 时间来源 |
| --- | --- | --- |
| 4 段（标准） | `01_01_0984_00.png` | 上传时刻 |
| 5 段（带时间） | `01_152325_01_0984_00.png` | 文件名中的时间 |
| 6 / 7 段（更旧） | `测试_01_..._CZ325_00.png` | 文件名中的时间，车牌取文件名 |

## 五、业务规则

### 5.1 判定矩阵

| 置信度 | 矿斗 | 车牌是否已知 | 结果 |
| --- | --- | --- | --- |
| ≥ 90% | 00 满载 | 已知 | **自动计次**，记为当日第 N 车 |
| ≥ 90% | 01 低于阈值 | 已知 | 告警「未满载卸矿」，**不计次** |
| 70% ~ 90% | 任意 | 已知 | 进复核队列 + 告警「识别置信度偏低」 |
| < 70% | 任意 | 已知 | 识别失败，待人工补录 |
| 任意 | 任意 | **未知**（档案无该车） | 车牌显示「未记录」、**不计次**、告警「未登记车牌」 |

### 5.2 计次规则

```
第 N 次 = 该车【当日】已计次的记录数 + 1
```

- 按「车辆 + 当日」累计，未计次的记录不占号；
- 同一文件重复上传自动去重（文件名 + 大小 + 修改时间作为幂等键）；
- 旧写法带来的车牌会自动写入车辆档案。

### 5.3 点位字段为 `00`

视为**不记录倒矿位置**：记录照常入库、仍可计次，点位显示「未记录」，并生成一条提示告警「未记录倒矿位置」，统计中单列「未记录」，不摊给具体点位。

### 5.4 车辆档案

- 首次打开自动预置 4 台车：

| 编号 | 车牌 |
| --- | --- |
| 01 | 鄂CZ325挂 |
| 02 | 鄂DK771挂 |
| 03 | 鄂M602挂 |
| 04 | 鄂T556挂 |

- 在「模拟数据接入」页的**车辆档案**卡片可新增 / 修改：填编号（2 位）+ 车牌（如 `鄂A12345挂`）→ 保存；同编号再次保存即更新车牌。

## 六、数据存储与同步

| 项 | 说明 |
| --- | --- |
| 存储位置 | 浏览器 localStorage，键名 `mt_sim_v1` |
| 保存内容 | 识别记录（最多 200 条）、告警、车辆档案、重量记录、操作日志 |
| 缩略图 | 只保留最近 24 条，控制体积；存储不足时自动丢弃 |
| 导出 | 右上角「导出数据」下载 JSON |
| 重置 | 右上角「重置演示数据」清空并重新预置车辆 |

### 各页面显示的数据

| 页面 | 同步内容 |
| --- | --- |
| 工作台 | 今日车次、待复核告警、最近流水表 |
| 可视化看板 | 今日车次指标、顶部实时数据条 |
| 识别计次 | 识别记录表（时间 / 车牌 / 点位 / 置信度 / 计次 / 状态） |
| 车辆定位 | 在途车辆列表 |
| 告警复核 | 告警列表（类型 / 级别 / 车牌 / 点位 / 状态）与复核操作 |
| 统计报表 | 车次指标、点位分布 |
| 移动端 H5 | 今日计次 |
| 项目实施 | 实时数据条 |

除「模拟数据接入」页自身已有指标卡外，其余各页面顶部都会显示「实时数据」横条：今日计次、待复核告警、识别记录数、平均置信度、最近上传时间，并提供「前往模拟接入」入口。数据变化后 5 秒内自动刷新。

## 八、已知限制

| 限制 | 说明 |
| --- | --- |
| 非真实识别 | 结果来自文件名约定，换一张内容不同但同名的图片结果不变 |
| 单机数据 | 数据存在当前浏览器，不跨设备、不跨浏览器 |
| 无后端 | 多人协作、真实并发、真实指标均未实现 |
| 图表数据 | 看板部分图表仍为原型静态示例，未全部接入本地数据 |
