## 一、项目简介

露天矿卸矿作业长期依赖人工登记与目视确认：车辆进出场无自动记录、倒矿车次靠人工点数、计量与卸矿环节相互割裂、异常停留与超限行为难以追溯，导致**计次不准、数据滞后、责任难界定**。

本项目围绕三条主线实现作业过程数字化：

| 核心                   | 建设内容                                                     |
| ---------------------- | ------------------------------------------------------------ |
| **车牌识别与自动计次** | 卸矿平台 / 计量点 / 排土点相机接入，识别车牌与置信度，按阈值自动计次，低置信度转人工复核与补录 |
| **倒矿作业过程管控**   | 进场登记 → 计量称重 → 卸矿作业 → 离场计次 四环节闭环，输出单车耗时、点位排队与作业效率 |
| **车辆定位与告警复核** | 露天电子围栏定位、轨迹回放、偏差监控；滞留超时、点位外停留、定位偏差超限等分级告警与人工复核留痕 |

系统由**服务端 Web 管理端**、**可视化看板（大屏）**、**移动端 H5** 三部分构成，全部内网部署，共用同一套业务接口与账号权限体系。

> 完整的背景、范围边界、实施策略与技术方案见 [《系统开发实施计划文档 V0.2.1》](进度计划/系统开发实施计划文档v0.2.1.docx)。

## 六、关键口径速查

| 口径           | 取值                                                         |
| -------------- | ------------------------------------------------------------ |
| 自动计次阈值   | 置信度 ≥ 90%                                                 |
| 人工复核区间   | 置信度 70%–90%，复核时限 20 秒/条                            |
| 识别失败       | 置信度 < 70%，转人工补录                                     |
| 重复计数控制   | 同一车辆 5 分钟内去重                                        |
| 告警分级与响应 | 紧急 2 分钟内、重要 5 分钟内                                 |
| 定位精度       | 验收底线 ≤ 10 米，刷新间隔 5 秒                              |
| 性能指标       | 并发 ≥ 200 路、可用率 ≥ 99.9%、查询 ≤ 2 秒、功能实现率 100%  |
| 售后响应       | 7×24；一般故障 4 小时响应 / 8 小时解决，重大故障 2 小时响应 / 24 小时到场 |

> 页面中的车牌、车辆、司机、时间与统计数据**均为演示数据**，不代表真实生产数据。

## 八、版本管理约定

仓库采用 `main`（稳定基线）+ `develop`（集成）+ `feature/*`、`fix/*`、`docs/*`（工作分支）的分支模型，合并使用 `--no-ff` 保留合并记录。

| 项目     | 规范                                                         |
| -------- | ------------------------------------------------------------ |
| 提交格式 | `type(scope): 简述`；scope 取 `prototype` / `wireframe` / `docs` / `repo` / `plan` |
| 提交粒度 | 一次提交只做一件事：页面按页提交，文档按章提交，素材单独提交 |
| 版本标签 | 按语义化版本打标签（如 `v0.2.1`），标签说明写明本次修订内容  |
| 基线对应 | 需求基线 V0.9 → `v0.9.x`；基线冻结 V1.0 → `v1.0.0`           |
| 忽略文件 | 系统临时文件、Word 锁文件（`~$*`）、依赖与构建产物           |

仓库根目录 `.gitignore` 至少包含：

```gitignore
# 系统与编辑器
.DS_Store
Thumbs.db
desktop.ini
.vscode/
.idea/

# Office 临时锁文件（打开 Word 时自动生成）
~$*

# 依赖与构建产物
node_modules/
dist/
```

> `招投标书及合同，需求文件/` 下现有 3 个 `~$…docx` 锁文件，属于本地打开文档时产生的临时文件，**不应提交**。
